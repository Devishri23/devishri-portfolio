Hotel Booking System

React JS | Spring Boot | MySQL | Bootstrap

🚧 In Progress

About the Project

Developing a full-stack Hotel Booking System that allows customers to browse and book hotels, while administrators and hotel managers can manage hotels, facilities, and bookings.

Technologies Used

React JS Spring Boot Spring MVC Hibernate MySQL Bootstrap REST API JWT

Key Features

  • 🔐 User Registration & Login with JWT Authentication
  • 👨‍💼 Role-Based Access — Admin, Hotel Manager & Customer
  • 🏨 Hotel Management — Add, Update, Delete & View Hotels
  • 📍 Location & Facility Management
  • ⭐ Hotel Reviews
  • 📅 Hotel Booking & Booking Status Management
  • 🗄️ MySQL Database Integration
  • 🔒 BCrypt Password Encryption
  • 🔗 REST APIs using Spring Boot
  • ⚛️ React JS Frontend (In Development)
