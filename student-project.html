Student Management System

Core Java | JDBC | MySQL

About Project

Student Management System is a console-based application developed using Core Java, JDBC and MySQL for managing student records.

Technologies Used

Core Java JDBC MySQL SQL

Features

  • Add Student
  • View Students
  • Search Student
  • Update Student
  • Delete Student

Database

MySQL database is used to store student information such as ID, name, course, email and marks.
